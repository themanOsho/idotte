## I would build these next, in this exact order

### 1. Printable Report Layout ⭐⭐⭐⭐⭐ (Next)

Right now the report is just React components.

You want it to print beautifully on A4.

Build:

```
ReportLayout
├── ReportHeader
├── ReportCover
├── MatchedTable
├── DuplicateTable
├── UnmatchedTable
└── ReportFooter
```

Then add print classes such as

* page breaks
* repeat table headers
* margins
* portrait layout
* print-only styles

This immediately makes Idotte usable.

---
