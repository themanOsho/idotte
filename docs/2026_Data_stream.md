# What to do when the 2026 data stream drops?
Now that your system has all the correct tools installed, it is 100% ready for both old and new Excel file types. When the 2026 data arrives, simply:

Create a new folder on your computer named Y2026 PLACEMENT LIST.

Put all your new 2026 Excel files into that folder.Copy your extract_zones.py script file and paste it into that folder.

Open PowerShell, navigate to the new 2026 folder, and run the script:
```powershell

cd "C:\Users\user\Documents\Y2026 PLACEMENT LIST" python extract_zones.py

```
Use code with caution.

Your 2026 extraction will run seamlessly across every single workbook without skipping anything.
